# Contributing

1. Read `AGENTS.md`, `BUILD-BASELINE.md` and `CURRENT-WORK.md`.
2. Branch from `main`, keep the change small, open a PR with the template filled in.
3. CI must be green. Routine PRs auto-merge; gated PRs wait for the owner (see `docs/release-policy.md`).
4. Record evidence in `CURRENT-WORK.md`: exact SHA, what ran, what did not.
5. Material technical choices get a short ADR in `docs/adr/` (context, decision, consequences, half a page).
6. Never commit private evidence, real conversations, names, business data or secrets. Fixtures are fictional or sanitized.
